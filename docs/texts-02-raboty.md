# Раздел 2: работы — список, редактор, выдача

Список видимых строк раздела для проверки (задача 5, шаг 2).

Проверяем три вопроса:

1. **Понятность** — прочитано без опыта работы с системой?
2. **Честность** — обещает ли текст то, что система делает?
3. **Простота** — нет ли технических деталей, которые пользователю не нужны?

Столбец «Решение» заполняется при проверке:

- `ок` — текст не требует правки;
- `заменить: …` — предложен новый текст;
- `удалить` — текст лишний.
